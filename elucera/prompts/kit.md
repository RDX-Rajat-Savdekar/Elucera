## Layout (use for EVERY scene)
- `<Stage title?="≤6 words" kicker?="LeetCode 206" titleAt?={f} titleOutAt?={f}>…</Stage>` — scene root: background + headline in the title band. Use it instead of a bare AbsoluteFill.
- `<Slot area="title"|"main"|"below" at?={f} outAt?={f} style?={css}>…</Slot>` — the three regions: title y200–440, **main y460–1180** (the diagram), below y1190–1400 (variables, a note, badges). Each slot holds ONE focal group; to change shots, give the old Slot `outAt` and a new Slot in the same area `at` a few frames later. Slots centre their content; to put two things side by side use `style={{ flexDirection: "row", gap: 60 }}`.
- Overlays (`Arrow`, `Callout`) are absolutely positioned in 1080×1920 px: keep them inside y 460–1180 and never on top of text.

## DSA / algorithm components — DATA, NOT DRAWING
Every structure takes its initial data plus `steps`: a list of `{ at: frame, …changes }`. **A step only lists what changes; everything else carries over** from earlier steps (`mark` / `edgeMark` REPLACE the previous marks; `pointers` / `badge` / `links` / `vars` MERGE, `null` removes). The component animates every change. Put each structure in a `<Slot area="main">` (variables/queues in `below`).

States (same everywhere): `"default" | "active"` (being examined, yellow) `| "compare"` (being read, cyan) `| "swap"` (being moved/written, magenta) `| "done"` (finished, green outline) `| "found"` (the answer, solid green) `| "visited" | "frontier"` (queued) `| "path"` (chosen path, solid yellow) `| "dim"` (ruled out) `| "error"`.

- `<ArrayView values={[…]} label? showIndex? cell? steps={[{ at, mark?: {i: state}, pointers?: {l: 0, r: 5, mid: null}, window?: [l, r] | null, swap?: [i, j], set?: {i: v}, values?, note?: "sum = 9" }]}/>` — arrays & two pointers, sliding window, binary search, sorting, prefix sums. `<StringView text="abcabcbb" …same/>` · `<BitRow value={13} bits={8} steps={[{at, value?, mark?: {bit: state}, note?}]}/>`
- `<Grid data={[[…],[…]]} rowLabels? colLabels? showIndex? steps={[{ at, set?: [[r, c, v]], mark?: {"r,c": state}, active?: [r, c] | null, deps?: [[r, c]…], note? }]}/>` — DP tables (deps draw the recurrence arrows), matrices, grid BFS/islands, game boards. Use `null` for empty cells.
- `<LinkedList values={[…]} steps={[{ at, links?: {i: j | null}, pointers?: {prev, curr, slow, fast}, mark?, removed?: [i], note? }]}/>` — reversal (re-pointed arrows curve back), cycle detection, merge, remove-nth. Default next of node i is i+1.
- `<SeqView kind="stack"|"queue"|"callstack" items? label? maxItems? steps={[{ at, items: [full contents], mark?, note? }]}/>` — push/pop/enqueue animate automatically from the full lists.
- `<HashMapView label? keyHeader? valueHeader? steps={[{ at, entries: [[k, v]…] (full), active?: key, op?: "a += 1", note? }]}/>` — counters, seen-sets, memo tables.
- `<BinaryTree tree={[3, 9, 20, null, null, 15, 7]} steps={[{ at, active?: id, mark?: {id: state}, edgeMark?: {childId: state}, badge?: {id: "2"}, visit?: [ids in order], hidden?: [ids], note? }]}/>` — LeetCode level-order input; **node id = its index in that array as a string** ("0", "1", "2", "5", "6"). Traversals, depth/height, BST search/insert (hide then reveal), LCA, path sums.
- `<Heap values={[…]} steps={[{ at, values?, swap?: [i, j], mark? }]}/>` — tree + array in sync; sift-up/down. `<Trie words={[…]} steps={[{ at, mark?: {"ca": "path"}, edgeMark?, note? }]}/>` — node ids are prefixes. `<RecursionTree root={{label, children?}} steps={[{ at, hidden?: [ids], mark?, badge?: {id: "ret"} }]}/>` — ids are paths "0", "0.1", "0.1.0"; reveal calls by shrinking `hidden`, return values as badges, memo hits as "visited".
- `<Graph nodes={[{id, x?, y?, label?}]} edges={[{from, to, w?, directed?}]} directed? steps={[{ at, mark?, edgeMark?: {"A-B": state}, badge?: {id: "dist"}, visit?, active?, note? }]}/>` — x/y in a 960×640 box (omit for a circle layout). BFS/DFS, Dijkstra, topo sort, union-find.
- `<Intervals intervals={[[1,3],[2,6]]} steps={[{ at, mark?, merged?: [[1,6]], sweep?: x | null, note? }]}/>` — merge intervals, meeting rooms, sweep line.
- `<CodePanel code={"…"} lang="python"|"js"|"java"|"cpp"|"go" title? steps={[{ at, line?: n | [from, to], reveal?: n, note? }]}/>` — syntax-highlighted solution; move the active line in sync with the narration.
- `<VarWatch vars?={{target: 9}} steps={[{ at, vars: {sum: 8} }]}/>` — live variables; changes flash.
- `<ProblemCard title num? difficulty="Easy"|"Medium"|"Hard" tags? input? output? at?/>` (put in `main`) · `<Complexity time="O(n)" space?="O(1)" vs?={{time: "O(n²)"}} at?/>` · `<ComplexityChart show? highlight="O(n log n)" at?/>`
